## 📱 Sobre ConsultiPY

**ConsultiPY** es un proyecto desarrollado como parte de una tesis de
Ingeniería Informática. El repositorio reúne recursos utilizados por la
aplicación Android y por el sitio web público del proyecto.

La aplicación integra distintas herramientas de apoyo, organización y
consulta, además de materiales informativos y recursos digitales. Parte
del contenido disponible en este repositorio se utiliza directamente
dentro de la aplicación, mientras que otros archivos forman parte del
sitio web publicado mediante GitHub Pages.

> **Importante:** ConsultiPY está publicado en la categoría **Estilo de
> vida** y su contenido tiene fines informativos y de apoyo general. No
> sustituye la evaluación, orientación ni atención de profesionales
> cualificados.

## 📚 Recursos incluidos

El repositorio contiene diferentes tipos de archivos, entre ellos:

-   documentos y materiales informativos;
-   libros y recursos en formato PDF;
-   imágenes utilizadas por el sitio web;
-   recursos gráficos utilizados por ConsultiPY;
-   archivos HTML, CSS y JavaScript del sitio público;
-   políticas de privacidad y eliminación de datos;
-   materiales de consulta utilizados o enlazados desde la aplicación.

Algunos documentos son recursos externos recopilados para su consulta.
La presencia de un archivo en el repositorio **no implica necesariamente
autoría de ConsultiPY**.

------------------------------------------------------------------------

## 🖼️ Recursos web

La carpeta `web/images/` contiene imágenes empleadas por las páginas
públicas del proyecto, incluyendo elementos de interfaz, logotipos,
ilustraciones y otros recursos visuales.

Los archivos HTML y sus dependencias se encuentran dentro de `web/`,
permitiendo que GitHub Pages publique el sitio directamente desde el
repositorio.

------------------------------------------------------------------------

## 📖 Documentos utilizados por la aplicación

Además del sitio web, este repositorio funciona como alojamiento de
determinados recursos que pueden ser consultados desde ConsultiPY, como
documentos y libros en formato digital.

Esto permite mantener recursos públicos accesibles mediante enlaces
estables sin incorporarlos necesariamente dentro del paquete instalable
de Android.

------------------------------------------------------------------------

## 🤖 Funciones con inteligencia artificial

ConsultiPY puede incorporar funcionalidades asistidas por inteligencia
artificial. Estas funciones deben considerarse herramientas
complementarias y sus respuestas pueden contener errores o información
incompleta.

No se debe utilizar una respuesta generada por IA como única fuente para
tomar decisiones importantes. El tratamiento de datos relacionado con
estas funciones se describe en la política de privacidad
correspondiente.

------------------------------------------------------------------------

## ⚠️ Aviso sobre los contenidos

Los materiales publicados tienen fines **informativos, educativos y de
consulta general**. Cuando un recurso pertenece a terceros, se mantienen
las referencias o atribuciones disponibles en el material original.

Los derechos de autor de libros, documentos, imágenes, marcas y demás
contenidos de terceros corresponden a sus respectivos titulares.

Si algún titular de derechos considera que un recurso no debería estar
disponible en este repositorio, puede comunicarse mediante el correo
indicado anteriormente para solicitar su revisión.
